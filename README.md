# Numtory 📊

**Numtory** is an Android application for tracking and comparing cryptocurrency and gold prices across Iranian exchanges and marketplaces.

The app brings prices from multiple sources into one place, making it easier to monitor the market, compare prices, and keep track of cryptocurrency and gold rates.

---

## ✨ Features

* 📈 **Cryptocurrency price tracking**
* 🪙 **Gold and coin price tracking**
* 🔄 **Multiple exchange support**
* ⚖️ **Price comparison between exchanges**
* 🌐 **Remote API-based market data**
* 🔔 **Firebase Cloud Messaging notifications**
* 🖼️ **Remote cryptocurrency and asset icons**
* 🚀 **Modern Jetpack Compose UI**
* 🌓 **Material 3 interface**
* ⚡ **Kotlin Coroutines**
* 💾 **Local data persistence**
* 🧭 **Type-safe navigation**
* 💉 **Dependency injection with Koin**

---

## 🏗️ Tech Stack

Numtory is built using modern Android development technologies.

| Technology                   | Purpose                          |
| ---------------------------- | -------------------------------- |
| **Kotlin**                   | Primary programming language     |
| **Jetpack Compose**          | Declarative UI                   |
| **Material 3**               | UI components and theming        |
| **Kotlin Coroutines**        | Asynchronous operations          |
| **Ktor**                     | Networking and API communication |
| **Kotlinx Serialization**    | JSON serialization               |
| **Koin**                     | Dependency injection             |
| **Room**                     | Local database                   |
| **Compose Destinations**     | Navigation                       |
| **Coil**                     | Image loading                    |
| **Firebase Cloud Messaging** | Push notifications               |
| **SLF4J**                    | Logging                          |
| **KSP**                      | Kotlin Symbol Processing         |

The repository currently uses Kotlin `2.2.20`, Android Gradle Plugin `8.13.2`, Compose BOM `2025.09.00`, and targets Android SDK 36.
